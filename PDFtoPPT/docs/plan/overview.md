# Project Overview — PDFtoPPT

**Date:** March 2026
**Owner:** Will Sullivan
**Status:** Active

---

## Goal

Automate the conversion of Power BI PDF exports into structured MBR PowerPoint decks, eliminating manual screenshot-and-paste workflows.

## Scope

- Extract dashboard visuals from Power BI PDFs
- Generate PPTX using MBR template
- Support batch processing of multiple PDFs
